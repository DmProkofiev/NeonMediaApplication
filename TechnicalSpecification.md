# Technical Specification: Neon Media Player 1.0.0

## 1. Назначение

Neon Media Player — кроссплатформенный медиаплеер для воспроизведения аудио и видео, редактирования метаданных медиафайлов и извлечения аудио из видеофайлов.

## 2. Технологический стек

- Язык: C# (.NET 10).
- Архитектурный паттерн: MVVM.
- Фреймворк: Avalonia.
- Архитектура: асинхронное оконное приложение (Avalonia).
- Хостинг: Microsoft.Extensions.Hosting для управления жизненным циклом, DI и фоновыми службами.
- MVVM-инфраструктура: CommunityToolkit.Mvvm.

---

## 3. Модели данных и связи

### 3.1. Сущности

**Доменные:**
	MediaFile — абстрактная сущность, представляющая медиафайл с его метаданными (название, артист, альбом, жанр, обложка и т.д.)
	Audio: MediaFile — наследник MediaFile, представляющий аудиофайл
	Video: MediaFile — наследник MediaFile, представляющий видеофайл

**DTO (Data Transfer Object):**
	AudioDTO — сущность для редактируемых пользователем полей

**Связующие:**
	Playlist — плейлист, содержащий коллекцию MediaFile. Может быть сохранён в формате JSON или XML для последующего импорта/экспорта

**Перечисления:**
	enum MediaType — тип медиафайла (Audio, Video)

---

## 4. Функциональные требования

### 4.1. CRUD-операции
- Создание (Create): добавление медиафайлов в библиотеку, создание плейлистов.
- Чтение (Read): просмотр списка медиафайлов, чтение метаданных.
- Обновление (Update): редактирование метаданных медиафайлов.
- Удаление (Delete): удаление медиафайлов из библиотеки и плейлистов.

### 4.2. Работа с медиафайлами
- создание и управление плейлистами;
- поддержка популярных форматов медиафайлов (MP3, MP4, AVI, MKV и др.);
- интеграция с движком VLC для декодирования и воспроизведения медиа;
- воспроизведение аудио и видео;
- извлечение аудио из видеофайлов;
- конвертация форматов;
- возобновление воспроизведения с последней позиции (асинхронная файловая операция логирования);
- редактирование метаданных файлов, в том числе обложка альбома.

### 4.3. Фоновые службы
- работа приложения в фоновом режиме.

---

## 5. Требования к пользовательскому интерфейсу

- кроссплатформенный интерфейс на базе Avalonia;
- визуальное оформление: неон с RGB-подсветкой;
- эффект размытого стекла (акрил) при перетаскивании окна курсором;
- поддержка тёмной и светлой тем;
- адаптивная вёрстка под различные разрешения экрана.

---

## 6. Нефункциональные требования

- Производительность: низкое потребление системных ресурсов, быстрое время запуска приложения.
- Надёжность: устойчивость к повреждённым медиафайлам, корректная обработка ошибок воспроизведения и извлечения аудио.
- Безопасность: локальное хранение данных, отсутствие передачи пользовательских данных в сеть.
- Совместимость: работа на основных операционных системах (Windows, Linux, macOS).
- Поддерживаемость: модульная архитектура, разделение на слои (доменные сущности, DTO, представление).
- Локализация: поддержка нескольких языков пользовательского интерфейса.
